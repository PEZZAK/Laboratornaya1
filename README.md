Поэтому цикл выполняется «минус y» раз (то есть модуль y), а в конце метод возвращает 1, делённую на полученное число. Например, для x = 2 и y = -2 получается 1 / 4 = 0,25. ### Алгоритм решения

Идея в том, чтобы по очереди брать цифры числа с конца и сравнивать каждую с первой взятой цифрой. Если хоть одна не совпала, ответ `false`.

## Задача 4

### Текст задачи

Добавление в массив. Сигнатура: `public int[] add (int[] arr, int x, int pos);`. Метод возвращает новый массив, содержащий все элементы массива arr, при этом в позицию pos вставлено значение x.

### Алгоритм решения

Размер массива в C# нельзя изменить после создания, поэтому сначала создаю новый массив на один элемент длиннее исходного. Потом переношу в него элементы в три этапа.

Сначала копирую в новый массив элементы исходного массива, которые стоят до позиции pos (индексы от 0 до pos - 1). Они остаются на тех же местах. Потом в ячейку с индексом pos записываю число x. В конце копирую оставшиеся элементы исходного массива (с индекса pos до конца), но каждый ставлю на одну ячейку правее, то есть элемент с индексом i попадает в ячейку i + 1.
